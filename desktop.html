Trad Center pour ordinateur

Le jeu en grand, en plein écran, toujours à jour.

⬇️ Télécharger l'appli

Comment l'installer
  1. Windows : ouvre Trad-Center-Windows.exe. Si « Windows a protégé votre PC » s'affiche : Informations complémentaires puis Exécuter quand même.
  2. Mac : ouvre le .dmg, glisse l'appli dans Applications, puis clic droit → Ouvrir la première fois (Puce Apple : arm64, Mac Intel : x64).
  3. Linux : rends le fichier .AppImage exécutable (chmod +x) puis lance-le.
L'appli n'est pas signée par un éditeur : l'avertissement est normal.
RaccourcisF11 plein écran · Ctrl + / Ctrl − zoom · Ctrl 0 zoom normal · F5 recharger.
Mises à jourLe jeu s'ouvre toujours à sa dernière version : rien à réinstaller à chaque nouveauté. Si l'appli elle-même change, le jeu te le dit.
Sur téléphone ?Il existe aussi une appli Android ; sur iPhone, ouvre le jeu dans Safari puis « Sur l'écran d'accueil ».
